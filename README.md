## 🔧 Project

- [Quality Management Monitoring Software](https://github.com/waqayaqoob21/Quality-Management-Monitoring-Software)
This is a Web-based software project that helps track and manage quality processes in an organization.

## Description

A comprehensive project for NESCOM, Islamabad, Pakistan, utilizing a robust tech stack and delivering a solution tailored to organizational needs. The frontend was built using Angular, ensuring an intuitive and dynamic user experience, while the backend was powered by Django Rest Framework for a scalable and efficient architecture. The application was deployed on an IIS server with PostgreSQL as the database, supporting high-performance data handling. The project featured 10 modules, including a documentation module, monitoring module, and a real-time chat system implemented with WebSockets. Additional functionalities included a user management system, seamless CSV file import to the database, dynamic form creation, and secure JWT-based authentication. This project demonstrates my expertise in full-stack development, system design, and deployment for mission-critical applications.
